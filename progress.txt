## Codebase Patterns
- The library uses optional peer dependencies for editor add-ons (e.g. `modern-monaco`, `@opencode-ai/sdk`), with config toggles in runtime config.
- Server-side sync helpers live under `src/server` and are exported from `index.ts`.
- Page metadata helpers (`PageMetaStore`, adapters) live in `src/server` for bun/sqlite and Cloudflare durable objects.
- Frontend sync uses storage keys prefixed with `<pageKey>:` to store per-file content alongside a `meta` entry.

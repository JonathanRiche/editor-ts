## Codebase Patterns
- The library uses optional peer dependencies for editor add-ons (e.g. `modern-monaco`, `@opencode-ai/sdk`), with config toggles in runtime config.
- `index.html` defines demo UI elements (like AI chat controls).
- `examples/quickstart.ts` wires UI IDs to `init()` config.
- AI chat behavior is centralized in `src/core/init.ts` and `src/core/aiChat.ts`.
